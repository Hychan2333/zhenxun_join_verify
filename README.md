# 真寻bot - 进群验证
一个适用于真寻bot的进群验证，可与welcome_msg联动

## 功能介绍
- 插件默认关闭
- 新成员进群后，bot会自动at新成员并发送题目，直接发送或回复bot答案即可通过验证并发送配置的进群欢迎消息。默认进群十分钟内无答案或是答错问题三次即踢出群聊（需bot拥有管理员权限）。
- 可在配置文件自定义验证超时时间 允许答错的最大次数 Bot无管理权限提醒冷却时间 Bot没有群管理权限时是否私聊通知提醒用户

## 处理流程
1. 插件开启时检查自身管理权限，若没有会通知进群验证提醒管理员，进群欢迎消息正常发送
2. 自身有管理权限时，会自动at新成员并发送验证题目
3. 新成员回复bot或是直接发送纯数字消息会验证答案对错，若发送了非纯数字消息或是答案错误会返回答案错误并消耗一次尝试次数
4. 若验证中途bot的管理员被取消，会发送流程中断的消息并通知进群验证提醒管理员
5. 验证通过会发送验证通过的消息并在后面附带进群欢迎的消息

## 配置说明

### 全局配置参数

在真寻Bot的Web UI或config文件中可以设置以下参数:

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| TIMEOUT | int | 600 | 验证超时时间(秒) |
| MAX_RETRIES | int | 3 | 允许答错的最大次数 |
| NOTIFY_WHEN_NO_PERMISSION | bool | true | Bot没有群管理权限时是否私聊通知提醒进群验证提醒管理员 |
| PERMISSION_NOTIFY_COOLDOWN | int | 600 | Bot无管理权限提醒冷却时间(秒)，避免重复刷屏 |

## 使用指南

### 群内管理命令(管理员权限)
```
开启被动 进群验证
关闭被动 进群验证
```

#### 提醒用户管理 (管理员权限)
```
添加进群验证提醒 123456789
移除进群验证提醒 123456789
```
